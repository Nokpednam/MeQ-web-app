# ขั้นตอนทดสอบ KPI-4: ระบบแจ้งซ่อม

ทดสอบบนเว็บจริงด้วยมือถือของคุณ (บัญชีแอดมิน) ใช้เวลาประมาณ 30 นาที ตรงกับตาราง Table 3.8 ในเล่ม (ขั้น S1–S7)

## ก่อนเริ่ม

- ใช้ **สนาม 5x5** ทุกขั้น เพราะสนามนี้ไม่มีรายงานจริงค้างอยู่ (เช็กแล้ว 15 ต.ค.) ส่วนรายงานที่ค้างอยู่ใน 3x3 A และ 3x3 B ห้ามแตะ
- รายละเอียดของทุกรายงานให้ขึ้นต้นด้วย `[ทดสอบ KPI-4]` ผมจะใช้คำนี้ดึงข้อมูลมาคำนวณ
- เตรียมรูปอะไรก็ได้ 1 รูปไว้แนบ (เช่นรูปพื้นปูน)
- ไม่ต้องจับเวลาเอง ระบบบันทึกเวลาของทุกขั้นและทุกข้อความ LINE ไว้แล้ว ให้จดแค่ว่าแต่ละขั้น **ผ่าน** หรือ **ไม่ผ่าน** และถ้าไม่ผ่านเห็นอะไร
- หน้าที่ใช้: แจ้งซ่อมที่เมนู **แจ้งซ่อม** (`/maintenance/new`), เปลี่ยนสถานะที่ `/admin/maintenance`

## ขั้นตอน

| ขั้น | ทำอะไร | ต้องเห็นอะไร | ผล |
|---|---|---|---|
| S1 | แจ้งซ่อม **R1**: สนาม 5x5, พื้นสนาม, รายละเอียด `[ทดสอบ KPI-4] R1 พื้นสนามแตก`, **แนบรูป** | ส่งสำเร็จ, รายการขึ้นใน "รายการของฉัน" สถานะ "รอแอดมินรับเรื่อง", **LINE แจ้งแอดมินว่ามีรายงานใหม่** | |
| S2 | แจ้งซ่อม **R2** ซ้ำ: สนาม 5x5, พื้นสนาม, `[ทดสอบ KPI-4] R2 แจ้งซ้ำ` (ขณะ R1 ยังไม่แก้) | **ส่งไม่ได้** ขึ้นข้อความ "สนามนี้มีรายงานปัญหาประเภทเดียวกันที่ยังไม่แก้ไข..." และไม่มีรายการใหม่ | |
| S3a | ที่ `/admin/maintenance` เปลี่ยน R1 เป็น **แอดมินรับเรื่องแล้ว** กดบันทึกสถานะ | LINE ถึงผู้แจ้ง "แอดมินรับเรื่องแจ้งซ่อมของคุณแล้ว" | |
| S3b | เปลี่ยน R1 เป็น **แจ้งผู้ดูแลแล้ว รอเข้ามาซ่อม** หมายเหตุ `โทรแจ้งผู้ดูแลแล้ว (ทดสอบ)` | LINE ถึงผู้แจ้ง "แจ้งผู้ดูแลสนามแล้ว..." พร้อมหมายเหตุ | |
| S3c | เปลี่ยน R1 เป็น **แก้ไขแล้ว** | LINE ถึงผู้แจ้ง "...แก้ไขเรียบร้อยแล้ว", "ประวัติการดำเนินการ" ของ R1 มี 3 บรรทัด | |
| S4 | แจ้งซ่อม **R3**: สนาม 5x5, พื้นสนาม, `[ทดสอบ KPI-4] R3 แจ้งใหม่หลังแก้แล้ว` | **ส่งได้** เพราะ R1 ปิดแล้ว, แอดมินได้ LINE | |
| S5 | แจ้งซ่อม **R4**: สนาม 5x5, **แป้นหรือห่วง**, `[ทดสอบ KPI-4] R4 ไม่มีรูป`, **ไม่แนบรูป** แล้วไปเปลี่ยน R4 เป็น **ไม่รับเรื่อง** หมายเหตุ `ข้อมูลทดสอบ` | ส่งได้แม้ไม่มีรูป, แอดมินได้ LINE, หลังไม่รับเรื่องผู้แจ้งได้ LINE "แอดมินไม่รับเรื่อง..." และ R4 ยังอยู่ในรายการ (ไม่หายไป) | |
| S6 | แจ้งซ่อม **R5**: สนาม 5x5, แป้นหรือห่วง, `[ทดสอบ KPI-4] R5 แจ้งใหม่หลังไม่รับเรื่อง` | **ส่งได้** เพราะการไม่รับเรื่องปิด R4 แล้ว | |
| S7 | เปลี่ยน R3 และ R5 เป็น **ไม่รับเรื่อง** หมายเหตุ `ข้อมูลทดสอบ` | ไม่มีรายงานทดสอบค้างเปิด, รายงานจริงของ 3x3 ไม่เปลี่ยน | |

## แคปหน้าจอระหว่างทาง (ใช้ในเล่มได้เลย)

ระหว่างทดสอบ แคปเก็บไว้ จะได้ภาพหน้าจอที่ยังขาดไปพร้อมกัน:

- ฟอร์มแจ้งซ่อมตอนกรอก R1 แล้วก่อนกดส่ง → `maintenance-form.png`
- หน้า `/admin/maintenance` ตอน R1 อยู่สถานะ "รอผู้ดูแล" → `admin-maintenance.png`
- แชต LINE ที่เห็นข้อความจาก MeQ หลายข้อความ → `line-chat.png`
- หน้า `/admin/maintenance/stats` หลังทดสอบเสร็จ → `admin-stats.png`

ส่งรูปมาได้เลย ผมจะตั้งชื่อและใส่ในเล่มให้

## เสร็จแล้ว

บอกผมว่าทำเสร็จ พร้อมผลผ่าน/ไม่ผ่านของแต่ละขั้น ผมจะดึงเวลาจากฐานข้อมูล (อ่านอย่างเดียว) มาคำนวณความเร็ว LINE และเติมผล KPI-4 ในบทที่ 4 และบทที่ 5 ให้

ถ้าขั้นไหนไม่ผ่าน อย่าแก้หรือลองใหม่จนผ่าน ให้จดไว้ตามที่เห็น เราจะรายงานตามจริงและแก้บั๊กแยกต่างหาก
